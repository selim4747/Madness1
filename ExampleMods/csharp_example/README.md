# My C# Mod

Bu örnek Mono masaüstü derlemesi içindir. `MyMod.cs` içindeki `SalePriceMultiplier` değeri 29.0f olarak ayarlanmıştır.

Önemli: Kaynak `.cs` dosyasını değiştirmek mevcut `Mod.dll` dosyasını otomatik güncellemez. DLL'i yeniden derleyip mod klasörüne kopyalamalısınız. Aynı ID'li built-in mod açıksa harici DLL modunun yüklenmesi bilerek engellenir; yalnızca birini etkin bırakın.
